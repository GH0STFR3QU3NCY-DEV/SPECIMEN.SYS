# Contributing

Thanks for helping improve SPECIMEN.SYS. Small, focused pull requests are easiest to review.

1. Create a branch for each change.
2. Keep the UI theme and pixel layout consistent; avoid unrelated visual redesigns.
3. Run `python -m unittest discover -s tests -v` and `python scripts/check_public.py` before submitting.
4. Include a comparison screenshot for changes to the artwork or animations.
5. Never commit virtual environments, user settings, local paths, API keys, personal information, signing credentials or unreleased third-party art.

Pull requests should describe **what changed**, **how it was tested**, and **what remains unverified**. Do not claim Windows GUI verification from a source-only test run.
